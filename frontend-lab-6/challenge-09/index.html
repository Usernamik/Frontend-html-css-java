Прибрати фіксовані .main{width:900px} і .card{width:300px} Так MDN: width Фіксована ширина більша за viewport дає horizontal overflow; заміна на Grid minmax(0,1fr) і auto-fit усуває причину.
Заmedia 3 штуки → один breakpoint Так web.dev: auto-fit repeat(auto-fit, minmax(min(100%,16rem),1fr)) сам перелічує колонки, тож breakpoint-и для 1024/768 (cards) зайві.
Додати min-inline-size: 0 grid-елементу Так MDN: min-width / Grid Grid/flex-елемент має min-width:auto і не стискається менше вмісту — це справжня першопричина overflow сайдбара/карток.
Замінити margin-left навігації на gap Так MDN: gap Gap єдиний для всіх елементів і не дублюється; margin лишає зайвий відступ у крайнього елемента.
Використати Container Query для картки Ні web.dev: container queries Тут достатньо Grid auto-fit: картки однакові й не змінюють внутрішній layout. CQ додав би складність без потреби (див. Challenge 5, де картка справді різна).
