# Лабораторна робота №1

Проста веб-сторінка з адаптивним дизайном та інтерактивним лічильником. Перша лабораторна з основ веб-розробки (HTML, CSS, JavaScript).

## Локальний запуск

Відкрий `index.html` у браузері — жодних залежностей не потрібно.

Або запусти через Live Server у VS Code:

```bash
# якщо встановлений live-server
npx live-server frontend-lab-1
```

## Деплой

- **GitHub Pages** — увімкни в налаштуваннях репозиторія → Pages → гілка `main`, папка `/frontend-lab-1`
- **Vercel** — імпортуй репозиторій на [vercel.com](https://vercel.com), Root Directory: `frontend-lab-1`
