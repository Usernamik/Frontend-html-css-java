# Мій список — starter-проєкт для ЛР №9

Каталог 30 серіалів TVmaze з пошуком, моїм списком і нотатками. HTML, CSS, дані й
модуль стану вже готові. Шар DOM — картки, обробники подій, форми, діалог і
керування фокусом — порожній: його й треба написати в лабораторній роботі.

 
## Склад

```text
index.html         уся статична розмітка: форма фільтрів, статус, список, шаблон картки, діалог
styles.css         стилі; стан показують атрибути aria-pressed і aria-invalid
data/shows.json    30 серіалів TVmaze
src/state.js       дані й стан (мій список, нотатки) — наданий, не змінюється
src/main.js        точка входу: показує список і підключає модулі нижче
src/render.js      C1 · картки й рядок статусу
src/list.js        C2 · кнопки карток
src/filters.js     C3 · форма фільтрів
src/details.js     C4 · діалог «Детальніше» і форма нотатки
check.html         самоперевірка; її код — у check/
experiments.html   розмітка для експериментів §4
```


## Дані

`data/shows.json` — адаптація даних [TVmaze](https://www.tvmaze.com)
([TVmaze API](https://www.tvmaze.com/api)): 30 із 240 серіалів першої сторінки
`https://api.tvmaze.com/shows?page=0`. Поля скорочено й спрощено (ті самі
записи й числа, що в ЛР-8, отримані 04.10.2026), опис `summary` — HTML-розмітка
TVmaze без змін, отримана 08.10.2026. Дані TVmaze поширюються за ліцензією
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/); ця адаптація —
за тією самою ліцензією. Якщо використовуєте дані деінде, зазначайте TVmaze як
джерело і зберігайте ліцензію.
