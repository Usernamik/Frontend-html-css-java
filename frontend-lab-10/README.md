# Courtly Booking — starter-проєкт для ЛР №10

Каталог майданчиків вигаданого сервісу Courtly: пошук за містом і видом спорту,
вибір дати, картки майданчиків, діалог бронювання та список бронювань. Це
**навчальний starter**: код написано так, ніби його швидко зібрали під дедлайн.
На перший погляд застосунок працює, але містить JavaScript-дефекти — знайти,
довести й виправити їх і є завданням лабораторної роботи.
